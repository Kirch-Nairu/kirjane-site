# Kirjane Labs Website — Implementation Ownership Update
**Effective:** 9 November 2026  
**Project repository:** `k3nchinxd/KirjaneWebSite`

## Decision

**Kurt (@k3nchinxd) is the sole designer and full-stack developer** of the Kirjane Labs corporate website.

The implementation responsibilities include UI/UX, React frontend, accessibility, responsive behavior, optional backend/API development, Netlify Forms configuration, testing, technical documentation, deploy preparation and maintenance.

**Kirch Ivan has no assigned frontend or backend implementation responsibilities for this website.** This is a change from the initial planning assumptions and prior repository descriptions. It does not imply that earlier planning, design, or technical discussions did not occur.

## Scope impact

The approved technology decisions remain unchanged:

- React + Vite + TypeScript + Tailwind CSS 4.
- React Router Framework Mode and six pre-rendered public routes.
- Netlify static hosting, Netlify Forms, GitHub pull requests and deploy previews.
- Controlled manual production publishing after company approval.

The static company website **does not need a custom backend, database, CMS, or authentication** for V1. Netlify Forms will handle basic inquiry processing once approved. If future requirements genuinely need backend logic, Kurt will design and implement it as a separate reviewed scope.

## Governance

Kirjane Labs still controls its official brand facts, public case-study permissions, domain, company inquiry records, and final release authorization. The GitHub account/repository is under Kurt's ownership. No publication is authorized by this document.

**Conflict resolution:** This update supersedes any prior statement describing Kirch as this project's backend developer or required technical reviewer. All other approved blueprint design and quality requirements remain in force.

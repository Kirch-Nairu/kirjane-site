# KIRJANE R4 — SENIOR DESIGN DIRECTION: RHYTHM-PRESERVING REFINEMENT

**Status:** Proposed visual direction, not owner acceptance.
**R3 source:** `7f3a3147c225aea8617820136b509306db3a143f`.
**Design thesis retained:** R3 **Living Topography / Engineered Clarity**.
**Scope:** Current active Kirjane imagery and motion. Original subject, silhouette, timing and interaction are the base—not a loose mood-board inspiration.

## What must improve
1. **Artistic finish:** actual depth, clean shape transitions, high quality bevels, surface roughness, controlled specular response, readable value contrast, material detail and purposeful shadows; do not generate a gallery of random engines.
2. **Color separation:** reduce repeated green-on-green, while keeping the existing emerald identity. Allow cobalt, cyan, pale ivory, titanium silver, warm amber and restrained violet/copper as supporting hues. Apply per actual object with intent; no blanket recolor.
3. **Motion finesse:** improve keyframe easing, camera steadiness, parallax, interpolation, shutter/blur where suitable, cohesive light changes and signal activity; do NOT break core phase order, scrub/reverse behavior, service selection or 23-scene story.
4. **Composition at real page scale:** make current subject legible, not tiny; preserve text space, hero hierarchy and responsive framing. A great Blender render is worthless if it reads badly behind website content.
5. **Faithful reconstruction:** when current site uses raster sources without editable 3D originals, Blender may recreate an editable version closely matching the SAME recognizable asset. Distinguish reconstruction fidelity from original .blend ownership.
6. **Performance and inclusion:** optimized posters/GLBs/frames only where justified, web fallbacks, reduced motion and browser/device evidence.

## Specific existing works to remaster, NOT reinvent
- **Services Automation:** current green paths through rings and Home four-mode scene. Keep a route/gate motif, refine lighting and dimensional treatment. Do not replace it with an invented mechanical assembly.
- **Home CGI:** fragmentation → clarity with the SAME narrative and scroll progress; better geometry/grade/camera, not a new plot.
- **Process:** five stages of the SAME existing topology; clearer lines, continuity, depth, contrast. Keep stage index and keyboard selection.
- **Salryn hero:** preserve the recognizable core + ring/satellite language. Improve metallic/ceramic separation and reduce visual crowding; don't substitute a different kernel.
- **Salryn documentary frames:** preserve 96 desktop + 48 mobile frame sequence beats, same transitions, richer light and supporting objects only when coherent.
- **Salryn configurator:** preserve eight engines, mandatory Security and Infrastructure, controls and state binding. Improve visual material clarity and selected-state lighting, not new engine claims.
- **Industry, offline and film:** preserve real illustrative states and ordered UI; upgrade presentation, not semantics.

## Creative decisions
- Focus on real continuity and visual hierarchy over novelty.
- No two-concept contest. A/b testing means two polish passes on one underlying asset when justified, not two unrelated subjects.
- No forced GLBs where a pre-rendered image is better.
- In every scene preserve the 3-second recognizability, 10-second explanatory meaning and 30-second interaction value.
- Grade for chapter-to-chapter variation: light editorial scenes allow warm neutral backgrounds, deep studio sections allow dark charcoal and colored key lights. Green remains the connective identity.
- If changing silhouette or overall staging would break continuity, do not implement it under the remaster brief; raise it to owner review.
- No official chameleon or wordmark changes.
